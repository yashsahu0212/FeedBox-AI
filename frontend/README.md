# feedBox AI Frontend Application ⚡

This directory contains the React 19 + Vite frontend application for **feedBox AI**.

## 🚀 Getting Started

```bash
npm run dev
```

Runs the app in development mode using Vite.

## 🛠️ Features

- **feedBox AI Header & Navigation**: Dynamic user profiles, role switching, and report counters.
- **AI-Powered Report Form**: Real-time auto-completion and AI classification preview.
- **Admin & Student Views**: Full department filtering and status timeline tracking.
- **Favicon**: Customized SVG favicon located in `public/favicon.svg`.
